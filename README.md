# 脚本分镜工具（门店内容）

给门店脚本做分镜处理的网页小工具：**加分镜 / 去出镜 / 加挂载 / 去分镜 / 替换表 / 红线检测**，外加规则库可视化编辑和「待补清单」反馈闭环。

## 怎么用

打开网页 → 顶部选门店 → 进对应页签 → 拖 Excel 进去 → 点处理 → 导出。

- **不联网也能用**：脚本内容只在你自己的浏览器里处理，**不会上传到任何服务器**
- 电脑上打开即可（Chrome / Edge 推荐），建议加书签
- 一次处理不了可以反复点，不会重复叠加

## 六个功能

| 页签 | 干什么 |
|---|---|
| ① 加分镜 | 给没标注的脚本补【分镜】；两种模式（真人出镜 / 无出镜）；新加的标注显示为绿色 |
| ② 去出镜 | 把【出境】换成实拍镜头；不会产出画外音/黑底白字 |
| ③ 加挂载 | 按日期给脚本加【挂私信】【挂定位】；没日期会拦住提示 |
| ④ 去分镜 | 删掉分镜【…】，白名单（bgm/卡点/门牌号）保留；被删的显示为红线 |
| ⑤ 替换表 | 城市/面积/区域/标志建筑 双向替换，可直接手打新值 |
| ⑥ 红线检测 | 扫极限词等红线词，只标红提示、不改字 |

每个功能都带：**筛选**（只看改动过的 / 没改的）、**重复劳动拦截**（该做的都做过了会提示）、**状态提示条**。

## 更新规则

规则都在 `rules.js`（预设：通用母版 / 佛山画巢奢石）。页面「⚙ 规则库」可可视化编辑并保存在本机；
需要全员统一更新时，把改动或「待补清单」发维护者，推送后**刷新页面即生效，链接不变**。
